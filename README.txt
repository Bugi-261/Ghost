Ghost - install files

Upload every file in this folder to your GitHub repository (not the folder itself):
  index.html
  manifest.webmanifest
  sw.js
  icon-180.png
  icon-192.png
  icon-512.png

Then: repository Settings > Pages > Branch: main, /(root) > Save.
Open the address it gives you in Safari on your iPhone > Share > Add to Home Screen.

To update later: upload the new index.html over the old one.
